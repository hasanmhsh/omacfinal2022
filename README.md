# Translated Chat (Textual and Vocal)

## Project description 
This project is a social communuication application for people  with different languages around all over the world to communicate with each other by providing translated chat for them ,
So that each one is able to use his native language to chat with others (of different languages) without need to know their languages.
This is the source code of mobile app of project, it is native android app developed with java programming language.
